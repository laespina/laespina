### 🔥 Featured project

🇧🇷 **[Licinexus/licinexus-mcp](https://github.com/Licinexus/licinexus-mcp)** — First Brazilian Model Context Protocol server for public procurement data. **16 tools, 4 prompts, MIT licensed.** Live in the [Official MCP Registry](https://registry.modelcontextprotocol.io).

```bash
npx -y @licinexusbr/mcp
```

Connects any MCP client (Claude Desktop, Cursor, Continue) to Brazil's National Procurement Portal (PNCP) and Federal Revenue CNPJ data — in natural language.
